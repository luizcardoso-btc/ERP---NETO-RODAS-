COMO SUBIR PARA O GITHUB (sem terminal)

O botao "Upload files" costuma deixar pastas de fora. Use o editor do proprio GitHub:

1. Descompacte este zip.
2. Abra seu repositorio no GitHub e aperte a tecla  .  (ponto).
   Abre um editor VS Code no navegador.
3. Arraste para a lista de arquivos da esquerda TODAS as pastas e arquivos de dentro
   da pasta descompactada (bin, src, pages, public, migrations, tests, deploy,
   Dockerfile, railway.json, composer.json, README.md ...). Se perguntar, escolha Replace.
4. Icone "Source Control" (barra lateral) > escreva uma mensagem > Commit & Push.

O Railway refaz o deploy sozinho. Se faltar alguma pasta, o build FALHA com a mensagem
"ERRO: <arquivo> nao esta no repositorio", dizendo exatamente o que falta.

No Railway, variaveis do servico do ERP (so estas duas):
  MYSQL_URL      = ${{MySQL.MYSQL_URL}}      (MySQL = nome do seu servico de banco)
  ADMIN_PASSWORD = uma senha de 10+ caracteres
